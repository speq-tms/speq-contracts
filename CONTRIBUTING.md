# Contributing to speq-contracts

## Workflow

- Branch from `main`.
- Keep schema changes atomic and documented.
- Update compatibility notes for contract changes.

## Commit style

Use Conventional Commit prefixes (`feat:`, `fix:`, `docs:`, `chore:`).

## Pull request checklist

- [ ] Schema changes are described.
- [ ] Compatibility impact is declared.
- [ ] Migration guidance exists for breaking changes.
- [ ] CI checks pass.
